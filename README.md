# 🏥 IncidentHub - Plateforme de gestion d'incidents IT

## 📌 Description
Application de gestion d'incidents pour équipes IT, avec authentification JWT, gestion des priorités et assignation des tâches.

## 🛠️ Stack Technique
- **Backend** : Node.js, Express.js, Sequelize
- **Database** : PostgreSQL (UUID primary keys)
- **Frontend** : React, Vite, Tailwind CSS 3.4.17
- **DevOps** : Docker, Kubernetes (GKE), GitHub Actions
- **Cloud** : Google Cloud Platform (GCP)

## 🚀 Statut du projet
En cours de développement - Phase d'apprentissage DevOps
